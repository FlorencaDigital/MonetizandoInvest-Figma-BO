# Monetizando Invest — BackOffice Wireframe

Wireframe interativo completo do BackOffice Monetizando Invest, gerado a partir do repositório `MonetizandoInvest-BackOffice` e alinhado ao Design System "Liquid Gold".

## Acesso

Acesse o wireframe publicado em: [GitHub Pages](https://florencadigital.github.io/monetizando-bo-wireframe/)

## Conteúdo

O wireframe cobre **53 telas** organizadas em **12 módulos**:

| Módulo | Telas |
|---|---|
| Login / Auth | Credenciais, TOTP Setup, TOTP Validate |
| Dashboard | KPIs, gráficos, transações recentes |
| Usuários | Contas, Detalhes (Cockpit 360), Admins, Permissões, Logs, Transferência |
| Empresas | Cadastros, Documentos, Compliance |
| Transações | Todas, PIX, TED, Boletos, Agendadas |
| PIX | Chaves, Cobranças, Devoluções, MED 2.0, Recorrências, Portabilidade |
| Financeiro | Investimentos, Saldos, Extratos, Limites, Tarifas |
| Segurança | Bloqueio Cautelar, Dispositivos, Auditoria |
| Relatórios | Operacional, Financeiro, Compliance |
| Asaas | Dashboard, Clientes, Cobranças, Assinaturas, Transferências, Extrato, PIX |
| Crédito (ESC) | Dashboard, Operações, Cedentes, Sacados, Calculadora, Registros CERC/B3 |
| Configurações | Geral, Notificações, Integrações |

## Design System

- **Cores:** Verde Monetizando `#004132` + Dourado `#D99D52` + Cream `#F8F5F0`
- **Fontes:** Inter (corpo) + Playfair Display (títulos)
- **Logo:** Ícone oficial Monetizando via CloudFront

## Tecnologia

Arquivo HTML único, self-contained, sem dependências externas (exceto Google Fonts e logo CDN). Hospedado via GitHub Pages.
